We recommend replacing HubSpot with a small CRM built on the firm's own Microsoft 365 and Azure. It covers Scott's five pillars, Monika's three Tier 1 dashboards and the round-table engine, and lets the firm cancel HubSpot in mid-January.

What it delivers

  • Scott's five pillars: pipeline, cadences, nurture, tasks and structure, plus the foundations he flagged, including a legally required suppression list.
  • Monika's Tier 1 dashboards: executive revenue and pipeline, rep performance, and pipeline conversion, emailed weekly so nobody has to log in.
  • Round-table engine: Janium registration sheets imported as prospects, with alumni tracked across sessions.
  • Integrations: Outlook mail and calendar sync, ZoomInfo enrichment, LinkedIn capture within LinkedIn's terms, and a full HubSpot migration.
  • AI where it saves Scott time: account summaries, meeting-note reports and follow-up drafts, running in the firm's own Azure tenant.

Solution architecture

One web app and one set of background jobs share a Postgres database. Microsoft 365 handles sign-in and mail, ZoomInfo enriches records, and Janium and HubSpot feed data in by import.

Integrations

Outlook and ZoomInfo have workable APIs. LinkedIn does not, so LinkedIn data comes in through pasted profile URLs, ZoomInfo matching and the Janium export.

Outlook / Microsoft 365 (Microsoft Graph)

  • Connection: each user connects once through Entra ID; admin consent for delegated mail, send and calendar permissions. Only mail to or from known contacts is stored.
  • Inbound: Graph change notifications for new mail, with a message delta query every 15 minutes as a backstop.
  • Outbound: cadence and task emails go out from the user's own mailbox, so they appear in Outlook Sent and replies land in Outlook.
  • Reply detection: matched on conversation ID and sender, not the subject line, so a changed subject still stops the cadence.
  • Calendar: meetings with an external contact become activities and drive "meetings booked".
  • Bounces and tracking: bounces exit the cadence in Phase 1; click and open tracking arrive in Phase 3, with opens shown as indicative only.

ZoomInfo

  • Access: the Enterprise API uses credentials issued by ZoomInfo's account team. The firm needs to confirm their package includes API access; today Scott uses the browser extension.
  • Cost control: searches are free and enrichment costs credits, so the app searches first and enriches only when a record is saved. ZoomInfo states one credit per new record, and re-enriching the same record within 12 months uses no new credits.
  • Flows: company enrichment on create, contact enrichment for work email and direct dial, and a quarterly check that flags people who changed employer.
  • Fallback: without API access, a ZoomInfo CSV export imports through the same mapping and dedupe rules.

LinkedIn

  • No profile API is available. LinkedIn's sales APIs require approval as a Sales Navigator Application Platform partner, and LinkedIn lists that access as closed. Scraping breaks LinkedIn's terms, so the design doesn't do it.
  • Capture: paste or share a profile URL from desktop or the LinkedIn phone app; ZoomInfo fills in name, title, email and company.
  • Janium: keeps running LinkedIn outreach and round-table registration; its 19-column sheet imports as prospects.

HubSpot migration

  • Export contacts, companies, deals, notes, emails, meetings, tasks, sequence templates and the round-table alumni list.
  • Run every row through the match keys and merge duplicate companies under their parents.
  • Proposal: import contacts with activity in the last 3 years plus all alumni, out of roughly 34–38K, and archive the rest as a file.
  • Reconcile counts, run both systems in parallel for two weeks, then cancel HubSpot.

Round tables, Read AI and AI services

  • Round-table sheets upload with a saved column map; a webhook later if Janium supports one.
  • Read AI transcripts are uploaded or forwarded, and AI drafts the opportunity report into notes.
  • Azure OpenAI writes account summaries, event follow-up drafts and the digest's narrative line. Nothing is sent without the user approving it.

Security, compliance and backups

The suppression list is the one non-negotiable control. CAN-SPAM penalties are assessed per email, up to $53,088 each after the FTC's 2025 inflation adjustment, and the law makes no exception for business-to-business email.

  • CAN-SPAM: every commercial email carries a working unsubscribe link and the firm's postal address. Unsubscribes go to a permanent list that every send and import checks.
  • Access: Entra ID sign-in with the firm's MFA policy; Admin, Seller and Viewer roles. Sellers export only their own records.
  • Data protection: encryption at rest and in transit; secrets in Azure Key Vault; API tokens never reach the browser.
  • AI data: Azure OpenAI inside the firm's subscription; prompts and outputs aren't used to train models.
  • Audit log: stage, picklist and record changes recorded with who and when.
  • Backups: Postgres point-in-time restore plus a nightly export kept 90 days, with a quarterly restore test. Any admin can export everything at any time.
